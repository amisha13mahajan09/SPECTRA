# SPECTRA

SPECTRA is a smart attendance management system built with Flutter and Python. It combines QR code scanning, geofencing, and facial recognition to make attendance marking faster, more secure, and more accurate.

## Features

- Login system for students and teachers
- Today's lecture schedule view
- QR code based attendance verification
- Geofencing to confirm classroom presence
- Facial recognition using OpenCV
- Attendance analytics and dashboards
- Subject-wise, daily, weekly, and monthly attendance tracking
- Defaulter list for teachers
- Secure and structured attendance storage using MySQL

## Tech Stack

- Flutter
- Dart
- Python
- OpenCV
- face_recognition
- MySQL
- REST APIs
- Flutter Charts

## Project Overview

SPECTRA stands for Smart Presence Evaluation and Classroom Tracking Recognition Architecture. It is designed to automate traditional attendance systems and reduce manual effort. The system uses a multi-layer verification process to prevent proxy attendance and ensure reliable attendance marking.

## How It Works

1. User logs in as a student or teacher
2. Student selects the current lecture from today's schedule
3. The app verifies attendance using QR code scanning
4. The system checks whether the student is within the classroom boundary using geofencing
5. Facial recognition is performed for final verification
6. Attendance is marked only if all checks are successful

## Objectives

- Automate attendance marking
- Prevent proxy attendance
- Generate real-time attendance statistics
- Maintain secure attendance records
- Reduce manual workload for faculty
